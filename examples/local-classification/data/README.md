# Local generated data

`data/processed/` is generated by `make prepare` and ignored by Git. The source
is the deterministic generator in `src/aai_local_classification/data.py`, so
the course needs no download and has no third-party data redistribution issue.

The generated manifest records row counts, time ranges, and SHA-256 digests for
all three files. It records prevalence for train and validation but deliberately
hides frozen-test prevalence until the release gate. Changing the generator,
seed, schema, or split boundaries creates a different dataset version and must
be treated as a new experiment input.
